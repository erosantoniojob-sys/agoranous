# Ágora welcome narration

`agora-welcome.pt-BR.v2.wav` was synthesized for this project with Kokoro 0.7.16,
using the Brazilian Portuguese `pm_santa` voice from Kokoro-82M.

- Model card: https://huggingface.co/hexgrad/Kokoro-82M
- Voice catalog: https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md
- Model license: Apache-2.0

The spoken script was written for Ágora. No browser speech-synthesis or remote
voice service is used by the narration.
